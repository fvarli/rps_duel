# RPS Duel

> A pocketable 30-second rock-paper-scissors duel. Tap, watch the CPU think, the result lands.

- **Store title:** `RPS Duel: Rock Paper Scissors`
- **Package id:** `com.lunexa.games.rpsduel`
- **Status:** live on Google Play Production · v1.0.4+5
- **Targets:** Android · iOS · Web · Linux (dev)

---

## Features today

### Gameplay
- Pure-Dart RPS engine; full 9-case truth table.
- CPU thinking beat (~500ms) before reveal; race-safe reset mid-thinking.
- 3-tier CPU difficulty (Easy / Normal / Hard) — Normal stays uniform random; Easy / Hard use 60/20/20 weighting toward losing / winning for the CPU.

### Scores & retention
- Player / CPU / Tie cards; round count; visible history (last 5 rounds).
- Current streak, best streak, win rate %.
- Daily Challenge — **7 objectives** that rotate by local calendar day (win N rounds / win with a specific move / tie N / reach a streak / just play N). Rolls over at midnight, including while the app is warm.
- 4 local achievements (First Win, Streak 3, Challenge Met, 10 Rounds) — chips on the game screen, a museum-style **Collection screen**, and an unlock toast.
- **Records screen** — lifetime totals, 7 discoverable narrative moments, move tendencies, and a timeline grouped Today / Yesterday / Earlier. Reached from the "Recent rounds" header or the round summary.
- Round history capped at the most recent 500 rounds; lifetime totals tracked separately and unaffected.

### App
- In-app Settings sheet: Difficulty · Language · **Sound** · Reset data · About.
- Six interaction sounds (tap / reveal / win / loss / tie / unlock) behind a persisted on/off switch, plus haptics on tap and reveal.
- In-app language picker: English / Türkçe / Español. All UI fully localized.
- Lightweight implicit animations (duel-area cross-fade, `AnimatedSize` on the surface card, score-digit fade).
- Mobile-responsive: max-width 460 column on desktop, overflow-tested at 360 wide.
- Material 3 with the baked-in "Tactile Premium" theme (cream paper / ink / sage / clay). Single light theme by design — no runtime theme swap.

### Persistence layout

All storage uses `shared_preferences`. Each concern owns its own key + class.

| Storage class | Key | Default on missing/corrupt | Cleared by Reset Game? |
|---|---|---|---|
| `LocalGameStorage` | `rps_duel.game_state.v1` | initial state | **Yes** |
| `LocaleStorage` | `rps_duel.locale.v1` | device locale | No |
| `DifficultyStorage` | `rps_duel.difficulty.v1` | Normal | No |
| `DailyChallengeStorage` | `rps_duel.daily_challenge.v2` (migrates `.v1`) | fresh for today | No |
| `AchievementStorage` | `rps_duel.achievements.v2` (migrates `.v1`) | empty map | No |
| `MatchMomentStorage` | `rps_duel.match_moments.v1` | empty map | No |
| `LifetimeStatsStorage` | `rps_duel.lifetime_stats.v1` | seeded from game state | No |
| `SoundEnabledStorage` | `rps_duel.sound_enabled.v1` | `true` | No |

Keys are version-tagged so schema changes go to the next `.vN` without breaking older blobs; both live migrations (`achievements`, `daily_challenge`) are read-repair and covered by tests.

> **Do not rename these keys, and do not rename any enum that is serialized into one.** `AchievementId`, `MatchMomentId` and `DailyChallengeKind` are all persisted **by name**, and `DailyChallengeKind.values` *order* is part of the daily rotation contract. `AchievementId.scissorsSpecialist` in particular keeps its historical name on purpose — its user-facing copy is now "Challenge Met", but renaming the enum would orphan every unlock already on a device.

### Launcher icon
**MVP placeholder brand icon** — three minimal white tokens (circle / rounded square / X representing rock / paper / scissors) arranged in an equilateral triangle on indigo. Generated by `scripts/generate_app_icon.py` and wired through `flutter_launcher_icons`. Reads as a game logo at small sizes (no text to go illegible). Still not designer-made — a final mark is on the release readiness checklist.

## Tech stack

Flutter 3.27+ · Material 3 · `go_router` · plain Dart `DuelController` driven by one `StatefulWidget` (**no Riverpod providers exist** — `ProviderScope` is mounted but unused) · `shared_preferences` · `audioplayers` · `intl` · `flutter_launcher_icons` (dev) · `flutter_lints` + strict custom analyzer rules.

**Scaffolded but still unused deps:** `riverpod_annotation`, `freezed_annotation`, `json_annotation`, `cupertino_icons`, and the `build_runner` / `freezed` / `json_serializable` / `riverpod_generator` dev chain. No `.g.dart` or `.freezed.dart` has ever been generated — all JSON is hand-written. `flutter_svg` and `connectivity_plus` were removed in 1.0.4 (the latter was pulling `ACCESS_NETWORK_STATE` into the release manifest for no reason).

## Roadmap

Tracking against `docs/html/handoff.html`. Confirmed deferred items:

**Shipped since this roadmap was written** (kept here so nobody rebuilds them): audio + haptics, achievement unlock toast, dedicated Achievements/Collection screen, Daily Challenge rotation, sound toggle, Records screen, narrative moments, lifetime stats.

**Product / UX — still open**
- Accessibility pass: there is currently **no `Semantics` and no `MediaQuery` usage anywhere in `lib/`**, so no text-scale or reduced-motion handling. Highest-value remaining polish.
- Real designed launcher icon (current mark is a self-described MVP).
- Replace the six placeholder sounds — `scripts/generate_placeholder_sounds.py` synthesizes them and its own docstring calls them non-production. Drop-in replacement, no code change.
- Haptics toggle in Settings (sound has one, haptics does not).
- Card-flip and physics animations.
- Pass-and-play (local 2-player). Note there is no seat/turn abstraction today — `DuelState` has exactly one `playerMove` and one `cpuMove`.
- CPU personalities. If built, drive them from the persisted `DuelState.history` rather than the current move: `RpsEngine.cpuMoveFor` on Hard *sees the player's move* and counters it 60% of the time, which is the most likely source of an "AI cheats" review.

**Architecture / platform — still open**
- Split `lib/ui/game/game_screen.dart` (759 lines; it owns all 8 storage handles and all orchestration).
- CI — there is none, and note `gradlew` + the wrapper jar are gitignored.
- R8 / minify: still off, release AAB is ~42 MB.
- Landscape + edge-to-edge / cutout.
- Online multiplayer / leaderboards / ranked / cloud sync.
- Ads / IAP.

**Superseded — do not action**
- ~~Riverpod migration~~ — `ProviderScope` is mounted with zero providers and four feature waves shipped without it. Revisit only if state genuinely outgrows the current owner.
- ~~Isar persistence~~ — eight `shared_preferences` classes with tested migrations are the real architecture.
- ~~Firebase analytics / crash reporting~~ — the live store listing promises "no analytics, no third-party tracking" in three languages and the Data Safety form answers No to all 18 questions. Adding any SDK requires re-declaring Data Safety, rewriting the policy, and rewriting store copy in en/tr/es. Run on Play Console + Android Vitals; revisit **Crashlytics only** at ~1k installs.
- ~~Theme engine / multiple `ThemePack`s~~ — the single Tactile Premium theme is the product identity.
