# RPS Duel

> A pocketable 30-second rock-paper-scissors duel. Tap, watch the CPU think, and the result lands.

- **Store title:** `RPS Duel: Rock Paper Scissors`
- **Package id:** `com.lunexa.games.rpsduel`
- **Status:** MVP-complete through Phase 8 (offline single-player vs CPU)
- **Targets:** Android · iOS · Web · Linux

---

## Features today (Phase 8 state)

- Pure-Dart RPS engine with the full 9-case truth table
- CPU thinking beat (~500ms) before reveal
- Score tracking (player / CPU / ties) + round count + history (last 5 visible)
- Reset confirmation dialog
- Local persistence via `shared_preferences` (survives app restart and browser reload)
- Lightweight implicit animations (duel-area cross-fade + score digit fade)
- Mobile-responsive layout (centered, max-width 460 on desktop; safe on 360-wide phones)

## Explicitly deferred (not in MVP)

- Theme engine / multiple themes
- Localization (en/tr/es ARBs are scaffolded; strings still in-code)
- Sound effects, haptics
- Card-flip / physics animations
- Riverpod state management
- Pass-and-play (local multiplayer)
- Online multiplayer, leaderboards, ranked mode
- Backend / auth / cloud sync
- Ads, in-app purchases
- Profile, achievements, daily missions
- Isar persistence (will replace `shared_preferences` when richer storage is needed)
- Final branded launcher icon (current icon is a **temporary dev placeholder** generated by `scripts/generate_app_icon.py` — indigo background with "RPS" lettering; replace with a real designed icon before any public release)

## Tech stack

Flutter 3.27+ · Material 3 · `go_router` · plain Dart `DuelController` (no Riverpod yet) · `shared_preferences` for local state · `flutter_lints` + strict custom analyzer rules.

## Setup

```bash
flutter pub get
flutter gen-l10n   # generates AppLocalizations stub from lib/l10n/*.arb
```

## Run

```bash
flutter run -d chrome              # web
flutter run -d linux               # desktop (Linux)
flutter run -d <android-device>    # Android device or emulator
flutter run                        # auto-pick the default device
```

## Test / analyze

```bash

```

## Project structure

```
lib/
├── main.dart                          # ProviderScope + MaterialApp.router
├── app/router.dart                    # GoRouter (one route today)
├── domain/                            # PURE DART — no Flutter imports
│   ├── move_choice.dart
│   ├── round_outcome.dart
│   ├── round_record.dart              # +toJson/fromJson for persistence
│   ├── rps_engine.dart                # 9-case truth table + cpuMove()
│   ├── duel_phase.dart                # idle, playerSelected, cpuThinking, reveal
│   ├── duel_state.dart                # immutable value object
│   └── duel_controller.dart           # selectMove / selectMoveWithDelay / nextRound / reset
├── data/
│   └── local_game_storage.dart        # shared_preferences wrapper
├── ui/game/
│   ├── game_screen.dart               # the only screen
│   └── move_button.dart               # reusable rock/paper/scissors button
└── l10n/                              # ARB stubs (en/tr/es)
test/                                  # 30 tests across the same layout
docs/                                  # design/handoff artifacts — see docs/README.md
```
