# RPS Duel

> A pocketable 30-second rock-paper-scissors duel. Tap, watch the CPU think, the result lands.

- **Store title:** `RPS Duel: Rock Paper Scissors`
- **Package id:** `com.lunexa.games.rpsduel`
- **Status:** MVP audit-complete through Phase 17
- **Targets:** Android · iOS · Web · Linux (dev)

---

## Features today (Phase 17)

### Gameplay
- Pure-Dart RPS engine; full 9-case truth table.
- CPU thinking beat (~500ms) before reveal; race-safe reset mid-thinking.
- 3-tier CPU difficulty (Easy / Normal / Hard) — Normal stays uniform random; Easy / Hard use 60/20/20 weighting toward losing / winning for the CPU.

### Scores & retention
- Player / CPU / Tie cards; round count; visible history (last 5 rounds).
- Current streak, best streak, win rate %.
- Daily Challenge — *Win 3 with Scissors today*. Auto-resets at next local date.
- 4 local achievements (First Win, Streak 3, Scissors Specialist, 10 Rounds) shown as chips on the game screen.

### App
- In-app Settings sheet: Difficulty · Language · Reset data · About.
- In-app language picker: English / Türkçe / Español. All UI fully localized.
- Lightweight implicit animations (duel-area cross-fade, `AnimatedSize` on the surface card, score-digit fade).
- Mobile-responsive: max-width 460 column on desktop, overflow-tested at 360 wide.
- Material 3 throughout (no custom theme engine yet).

### Persistence layout

All storage uses `shared_preferences`. Each concern owns its own key + class.

| Storage class | Key | Default on missing/corrupt | Cleared by Reset Game? |
|---|---|---|---|
| `LocalGameStorage` | `rps_duel.game_state.v1` | initial state | **Yes** |
| `LocaleStorage` | `rps_duel.locale.v1` | device locale | No |
| `DifficultyStorage` | `rps_duel.difficulty.v1` | Normal | No |
| `DailyChallengeStorage` | `rps_duel.daily_challenge.v1` | fresh for today | No |
| `AchievementStorage` | `rps_duel.achievements.v1` | empty set | No |

All keys are `.v1`-tagged so future schema changes can go to `.v2` without breaking older blobs.

### Launcher icon
**MVP placeholder brand icon** — three minimal white tokens (circle / rounded square / X representing rock / paper / scissors) arranged in an equilateral triangle on indigo. Generated by `scripts/generate_app_icon.py` and wired through `flutter_launcher_icons`. Reads as a game logo at small sizes (no text to go illegible). Still not designer-made — a final mark is on the release readiness checklist.

## Tech stack

Flutter 3.27+ · Material 3 · `go_router` · plain Dart `DuelController` (no Riverpod yet) · `shared_preferences` · `flutter_launcher_icons` (dev) · `flutter_lints` + strict custom analyzer rules.

**Scaffolded but currently unused deps** kept from the original Phase 0 spec for upcoming phases: `riverpod_annotation`, `freezed_annotation`, `json_annotation`, `flutter_svg`, `connectivity_plus`. Imports will land when the phases that need them do.
