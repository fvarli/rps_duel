# store-assets/

Binary deliverables for the **Google Play Store listing**, generated from source where possible. These are NOT app build outputs — they're the listing assets the operator uploads to Play Console alongside the release AAB.

For listing **copy** (descriptions, release notes, content rating, Data Safety) see [`../docs/play_store_launch.md`](../docs/play_store_launch.md).
For the build / signing workflow see [`../docs/release_android.md`](../docs/release_android.md).

## Layout

```
store-assets/
├── README.md                          ← this file
├── feature_graphic/
│   ├── generate_feature_graphic.py    ← Python+PIL script
│   └── feature_graphic.png            ← 1024×500 listing header (generated)
└── screenshots/
    ├── CAPTURE_GUIDE.md               ← 8-frame setup + capture instructions
    ├── capture.sh                     ← adb screencap wrapper
    └── screenshot_<N>.png             ← captured frames (operator step; not yet committed)
```

## Regenerating the feature graphic

```bash
python3 store-assets/feature_graphic/generate_feature_graphic.py
```

The script reads no inputs — palette and motif are pinned in the source. The output PNG is the v1.0.0 listing header. Re-run any time the Tactile Premium palette changes in [`../lib/ui/theme/tactile_theme.dart`](../lib/ui/theme/tactile_theme.dart).

## Capturing screenshots

See [`screenshots/CAPTURE_GUIDE.md`](screenshots/CAPTURE_GUIDE.md). Briefly: connect a device or emulator, then run `screenshots/capture.sh N` for each of the 8 frames listed in the guide. Captured PNGs land in `screenshots/screenshot_<N>.png` and can then be uploaded to Play Console.

## What lives where

| Asset | Play Console requirement | Source in this repo |
|---|---|---|
| 512×512 app icon | Required | [`../assets/app_icon/app_icon.png`](../assets/app_icon/app_icon.png) (generated by [`../scripts/generate_app_icon.py`](../scripts/generate_app_icon.py)) |
| 1024×500 feature graphic | Required | `feature_graphic/feature_graphic.png` |
| Phone screenshots | Required (2–8 frames) | `screenshots/screenshot_*.png` (operator captures) |
| 7" tablet screenshots | Optional | Deferred. |
| 10" tablet screenshots | Optional | Deferred. |
| Promo video | Optional | Not used for v1.0.0. |
